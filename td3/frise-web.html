Repères chronologiques

Cette frise prolonge l'ancien exercice sur l'histoire du Web. Les événements et leurs dates sont fournis : au TD3, vous diagnostiquez leur présentation, non leur contenu historique.

  1. 1989

    Naissance du World Wide Web

    Au CERN, Tim Berners-Lee propose un système de documents reliés par des liens hypertextes, à l'origine du Web.

    Découvrir les archives du CERN

  2. 1993

    Mosaic et le Web graphique

    Le navigateur Mosaic contribue à populariser la navigation graphique sur le Web.

  3. 1995

    JavaScript

    JavaScript apporte de nouvelles possibilités d'interaction dans les pages Web.

  4. 1996

    Première recommandation CSS

    Les feuilles de style permettent de distinguer davantage les contenus HTML de leur présentation.

    Consulter l'histoire des CSS au W3C

  5. 2001

    Wikipédia

    Une encyclopédie collaborative montre la place croissante de la contribution des internautes.

  6. 2003

    WordPress et les CMS

    Les systèmes de gestion de contenu facilitent la publication sans écriture manuelle de chaque page.

  7. 2005

    Applications Web interactives

    Des interfaces utilisant AJAX peuvent actualiser une partie d'une page sans la recharger entièrement.
