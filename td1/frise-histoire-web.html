Une brève histoire du Web

Document pédagogique du TD1 — Culture numérique S5

1989–1991 — Naissance

Tim Berners-Lee propose le World Wide Web au CERN : hypertexte, URL, HTTP et HTML deviennent les éléments fondateurs.

1993 — Mosaic

Le navigateur Mosaic contribue à populariser le Web graphique.

1995 — JavaScript

JavaScript apporte des comportements interactifs aux pages Web.

1996 — CSS

Les feuilles de style permettent de séparer présentation visuelle et structure HTML.

Années 2000 — CMS et participation

Wikipédia, les blogs et les CMS facilitent la publication et la contribution sur le Web.
