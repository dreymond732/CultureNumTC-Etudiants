# Sorties fictives pour interprétation (ne représentent pas le réseau de l'IUT)
# Les plages 192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24 sont réservées aux exemples.
$ ping -c 4 127.0.0.1
4 packets transmitted, 4 received, 0% packet loss
# Cette réponse ne prouve pas l'accès à Internet.
$ ping -c 4 198.51.100.42
4 packets transmitted, 0 received, 100% packet loss
# La cible ou ICMP peuvent être filtrés.
$ nslookup example.org
Server: 192.0.2.53
Name: example.org
Address: 198.51.100.15
# Illustration, pas une résolution DNS réelle.
$ traceroute example.org
 1  192.0.2.1    1.2 ms
 2  * * *
 3  198.51.100.1  15.0 ms
