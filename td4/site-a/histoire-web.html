Une brève histoire du Web

Comment le Web s'est-il développé ?

1989–1991 — La naissance du Web

Tim Berners-Lee, au CERN, propose le World Wide Web. Les liens, les URL, HTTP et HTML permettent de relier des documents accessibles en réseau.

1993 — Le navigateur Mosaic

Mosaic contribue à diffuser l'utilisation de navigateurs graphiques.

1995 — JavaScript

JavaScript est créé chez Netscape et permet d'ajouter des interactions aux pages Web.

1996 — CSS

Les feuilles de style CSS permettent de séparer la présentation visuelle de la structure HTML.

Années 2000 — Participation et CMS

Wikipédia, les blogs et les CMS facilitent la publication et la contribution sur le Web.
